Política de privacidade — Tupi Bruno

Última atualização: 07/11/2026

Quem usa

O Tupi Bruno é um assistente pessoal privado, usado por uma única pessoa, que autorizou o acesso à própria conta Google.

Quais dados acessa

Com a autorização do usuário, o assistente pode acessar Gmail, Google Drive, Agenda, Documentos, Planilhas, Apresentações, Formulários, Tarefas, Contatos e Apps Script dessa conta.

Como usa

Os dados são usados apenas para executar o que o próprio usuário pede ao assistente. Não são vendidos, não são usados para publicidade e não são compartilhados com terceiros, exceto os provedores técnicos necessários para o assistente funcionar (servidor e modelo de IA), sob as mesmas restrições.

O uso de informações recebidas das APIs do Google segue a Google API Services User Data Policy, incluindo os requisitos de uso limitado (Limited Use).

Armazenamento

As credenciais de acesso ficam criptografadas em um servidor privado. Conteúdos são guardados apenas pelo tempo necessário para a tarefa pedida ou conforme o próprio usuário solicitar.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
